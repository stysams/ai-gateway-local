# ai-gateway 功能清单与当前版本记录

> 文档日期：2026-08-24
> 当前版本：`0.1.0-rc1`（Windows amd64）
> 当前结论：功能主线已完成，第一期保留五项真实验收遗留；本清单不产生其他版本规划。

这份清单是当前版本的单一入口。它按照用户可见能力、技术保障、验证证据和剩余历史门项组织，不替代 [v1-scheme.md](v1-scheme.md) 的协议合同，也不修改原始验收记录。除非用户明确提出新的版本任务，不根据本清单继续扩展功能范围。

## 状态说明

| 状态 | 含义 |
|---|---|
| 已完成 | 功能已经实现，并且有代码或自动化测试证据。 |
| 已验收 | 已在 Windows 11 发布版或真实客户端链路中完成验证。 |
| 延期 | 功能不是当前使用阻断项，真实验收尚未完成，作为当前版本历史遗留记录。 |
| 环境阻塞 | 已有实现，但当前机器或用户权限无法完成真实验收。 |
| 待收尾 | 功能本身已经完成，但发布物、文档或证据在当前版本中只保留记录。 |
| 已记录 | 差异或历史事项已经记录，不在当前版本自动安排处理。 |
| 不纳入 | 明确不属于当前版本的交付范围。 |

## 九、当前版本结论

当前版本记录使用以下边界：

1. `0.1.0-rc1` 是当前唯一版本基准。
2. 本清单中所有“已完成”和“已验收”项保持不回退，五项历史遗留不改写为已验收。
3. 发布包元数据以 `docs/progress.md` 和 `docs/releases/release-notes.md` 的实测值为准。
4. 不从本清单、路线图或历史验收遗留中自动派生新的版本规划。

当前结论：**`0.1.0-rc1` 功能开发已收尾；发布包与源码主线的差异以及五项历史验收遗留均已记录，不自动扩大当前版本范围。**

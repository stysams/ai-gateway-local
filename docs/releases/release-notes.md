### 版本内容

- 日志默认在写盘前递归脱敏常见凭据字段，覆盖嵌套 JSON、请求头、JSON 字符串和 SSE 数据帧；自由文本隐私风险仍会明确提示。
- 日志列表新增强制脱敏复制与 JSONL 下载、单条删除和非活动日志批量清理；活动请求日志不会被误删。
- 管理接口新增脱敏导出与清理端点，`PUT /api/v1/logging` 支持独立控制 `redact`。
- Chat Completions、Responses 与 Messages 的跨协议 IR 新增 JSON Schema 结构化输出和严格函数工具定义，三个转换方向均有自动化测试。
- 桌面管理界面采用更紧凑的宽屏排版，同组设置、连接参数、状态信息和客户端路由可以在同一行完成查看与操作。
- 供应商编辑器根据字段内容重新分配横向空间，减少不必要的纵向滚动，同时保留长地址和模型标识的完整显示能力。
- 中等宽度和移动端继续自动重排为双列或单列，保持输入、状态和操作按钮可读且可访问。
- 设置页对端口、日志和资源限制提供字段级错误说明；监听地址切换到 `0.0.0.0` 时显示网络暴露提示，并在保存前要求确认。
- 客户端路由在窄屏下展示模型完整值，日志记录显示完整日期和时间，移动端底部导航在首屏内保持全部入口可达。
- 日志与供应商列表中的操作按钮统一成稳定的操作组，桌面端保持同一基线，移动端日志操作区改为两列布局。
- 全局滚动条采用更窄的尺寸和稳定的滚动槽，日志表与详情抽屉滚动时不会造成内容跳动或横向溢出。
- 供应商伪装客户端新增 Pi。第三方 `/v1` 请求可使用 `User-Agent: Pi Agent/1.0` 模拟 Pi 身份；桌面供应商表单同步提供可编辑的 Pi 请求头预设。
- 客户端高级设置支持为 Codex 与 Claude Code 分别指定子代理模型和标题生成模型；未指定、已禁用或失效的模型会跟随当前客户端路由。

### 2026-08-25

- Claude Desktop 支持在客户端页面中完成指向网关、状态检查和默认路由同步。
- Claude Desktop 的推理 profile 与 MCP 配置分别显示状态，并提供独立的还原操作；MCP 完整还原需要明确确认。
- Claude Desktop 的配置发现覆盖 `%LOCALAPPDATA%\Claude`、`%APPDATA%\Claude` 和 `%LOCALAPPDATA%\Claude-3p`。
